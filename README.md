# Portfolio Site 2026 - "Ocean"

A portfolio site made using [Astro](https://astro.build) and very little else.

Made out of necessity and also as a chance to test out [CUBE CSS](https://cube.fyi) and [Utopia](https://utopia.fyi); there's ~~not a single media query in this website~~ only one media query and it's for reduced motion checking! Otherwise, no screen size queries, and the site should still be fully responsive!

_A better, more human web is possible!_
