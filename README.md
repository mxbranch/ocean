# Portfolio Site 2026 - "Ocean"

[![Netlify Status](https://api.netlify.com/api/v1/badges/9ec45ff7-dbf9-4fb1-abeb-a84a9bbe7c54/deploy-status)](https://app.netlify.com/projects/mxbranch-ocean/deploys)

A portfolio site made using [Astro](https://astro.build) and very little else.

Made out of necessity and also as a chance to test out [CUBE CSS](https://cube.fyi) and [Utopia](https://utopia.fyi); there's not a single media query in this website and it should be fully responsive!
